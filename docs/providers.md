# Provider balance coverage

Inventory of the 41 built-in provider IDs in the installed Pi model catalog (`@earendil-works/pi-ai`), checked against provider API documentation. This is **account balance / subscription quota**, not the model's context window, request rate limit, past spending, or an API-key spending cap. Pi supplies the active model's credential, whether configured in `auth.json`, environment, or through OAuth. Third-party/custom providers are unknown and display `Quota non disponibile`.

| Pi provider ID | Status | Official reference |
| --- | --- | --- |
| `openrouter` | Account credit = `total_credits - total_usage` (USD), **only if Pi's credential is an OpenRouter management key**; normal inference keys receive HTTP 403 and show unavailable. | [Get remaining credits](https://openrouter.ai/docs/api/api-reference/credits/get-remaining-credits), `GET https://openrouter.ai/api/v1/credits` |
| `openai-codex` | Remaining subscription quota for the primary and secondary usage windows (typically 5h / 7d), from `100 - used_percent`; Pi's OAuth token and ChatGPT account ID are required. This backend route is used by the official Codex client but is **not a stable public API**. | [Official Codex client usage request](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/client/rate_limit_resets.rs), [response fields](https://github.com/openai/codex/blob/main/codex-rs/codex-backend-openapi-models/src/models/rate_limit_status_details.rs), `GET https://chatgpt.com/backend-api/wham/usage` |
| `deepseek` | Available balance per currency (CNY and/or USD); no currency conversion. | [Get User Balance](https://api-docs.deepseek.com/api/get-user-balance), `GET https://api.deepseek.com/user/balance` |
| `moonshotai` | Available balance, USD. | [Balance](https://platform.moonshot.ai/docs/api/balance), `GET https://api.moonshot.ai/v1/users/me/balance` |
| `moonshotai-cn` | Available balance, CNY. | [Balance](https://platform.moonshot.cn/docs/api/balance), `GET https://api.moonshot.cn/v1/users/me/balance` |
| `amazon-bedrock`, `azure-openai-responses`, `cloudflare-ai-gateway`, `cloudflare-workers-ai`, `google-vertex`, `radius`, `vercel-ai-gateway` | Cloud/gateway billing belongs to separate accounts/credentials; no verified remaining plan balance endpoint with Pi's inference credential. | Provider-specific cloud billing tools, not Pi model API keys. |
| `anthropic`, `openai`, `github-copilot` | Subscription balance not exposed through a verified quota endpoint accessible with Pi's inference/OAuth credential. Admin usage/spending APIs are **not** plan remainder. | [Anthropic Admin usage/cost](https://platform.claude.com/docs/en/api/admin-api/usage-cost-api), [OpenAI organization costs](https://platform.openai.com/docs/api-reference/organization/costs) |
| `fireworks`, `together` | Documented billing usage / quotas are past spend or request limits, not an available credit balance verified for inference keys. | [Fireworks billing summary](https://docs.fireworks.ai/api-reference/get-billing-summary), [Together billing usage](https://docs.together.ai/reference/billing-usage) |
| `ant-ling`, `baseten`, `cerebras`, `google`, `groq`, `huggingface`, `kimi-coding`, `meta`, `minimax`, `minimax-cn`, `mistral` | No verified official endpoint returning remaining allowance with Pi's inference credential. | Check provider billing documentation before adding integrations. |
| `nvidia`, `opencode`, `opencode-go`, `qwen-token-plan`, `qwen-token-plan-cn`, `qwen-token-plan-individual`, `xai`, `xiaomi`, `xiaomi-token-plan-ams`, `xiaomi-token-plan-cn`, `xiaomi-token-plan-sgp`, `zai`, `zai-coding-cn` | No verified official endpoint returning remaining allowance with Pi's inference credential; management/billing credentials, if available, are distinct. | Check provider billing documentation before adding integrations. |

An HTTP 401/403, invalid response or missing credential always yields `Quota non disponibile` without suppressing the notification. OpenRouter's `/api/v1/key` reports a **per-key** limit, not remaining account credit: deliberately not used. This inventory is for the Pi catalog present at implementation time; new providers require fresh verification.
